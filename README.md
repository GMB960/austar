# Remix of Austar Energy Experience

Check these attached prompts (Austar-Energy-Lovable-Prompt.txt and Revise the Austar Energy website's creative direction) to understand what sort of modern website I want. Make sure the website is top of the top, like a 50000$ website, it should feel and look alive, I don't want anything common or normal, I want something extraordinary, every story, every section has to be something unique, something modern, something understanding, animated. Also use real images on the website, do not make fake or AI generated images. Make every section working like a multi pages website, every section should be working with animations and proper informative content.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://austar.lovable.app
